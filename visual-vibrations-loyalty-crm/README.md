# Visual Vibrations — Customer Loyalty + CRM

Customer loyalty, CRM, sales and service workspace for **Visual Vibrations Pvt. Ltd., Nagpur**.

## Business Verticals

- Modular Kitchens — Modulinea
- Home Automation
- Home Theatre / Audio Video
- Architectural Lighting

## Working Product

The responsive MVP includes:

- Customer 360° profiles and purchase history
- Customer search, segmentation and cross-selling signals
- Loyalty points, membership tiers, rewards and vouchers
- Referral programme and occasion rewards
- Sales and lead pipeline management
- AMC renewal reminders and service activity
- WhatsApp/SMS campaign workflows and audience builder
- Admin dashboard and management analytics
- CSV customer export
- Device-local persistence for product demonstrations
- Secure, integration-ready delivery worker

## Production Integrations

WhatsApp, SMS, payment, accounting/ERP and other external services require the client's chosen provider accounts, API credentials and final commercial rules before production activation.

## Render Deployment

Create a **Web Service** from the repository and use:

- Root Directory: `visual-vibrations-loyalty-crm`
- Runtime: `Node`
- Build Command: `npm install`
- Start Command: `npm start`

The server automatically uses Render's assigned `PORT` and binds to the public service interface.
